## 📉 Customer Retention Analytics using SQL

🔗 **Repository:** https://github.com/RithikaRajeev01/customer-retention-analytics-sql

Built an end-to-end SQL analytics pipeline using **7,043 telecom customer records** to identify churn drivers, segment customers by lifetime value, prioritize retention efforts, and translate analysis into business recommendations.

* Identified a **26.54% customer churn rate** and analyzed demographic, contract, service, and revenue-related churn patterns.
* Used advanced SQL including **CTEs, Dynamic SQL, NTILE(), ROW_NUMBER(), CASE statements, and INFORMATION_SCHEMA** for data validation, segmentation, ranking, and risk scoring.
* Found that **month-to-month customers churn at 42.71% compared with 2.83% for two-year contracts**, identifying contract duration as the strongest retention driver in the analysis.
* Segmented customers by lifetime value and found that the highest-value group generates approximately **37× more lifetime revenue** than the lowest-value group.
* Developed a rule-based customer risk scoring framework identifying **599 high-risk customers** for targeted and cost-effective retention campaigns.

**Tech Stack:** SQL, MySQL 8, CTEs, Window Functions, Dynamic SQL, Data Cleaning, Customer Segmentation, Risk Scoring
